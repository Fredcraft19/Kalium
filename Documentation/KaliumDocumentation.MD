# Kalium Documentation

Kalium is awfully simalar to C++ when it comes to variable declaration, methods and classes/structs (Except the lack of 'public'/'private' and static variables, static methods exists)

Therefore you can somewhat assume to type in normal C++ until you run into a compiler error.

## Variable Declaration
How to declare variables in Kalium
```cpp
type name;
// or
type name = value;
```

Examples:
```cpp
int a = 10;

int a = 10 * 11;
```
